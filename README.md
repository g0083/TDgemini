# CYBER DEFENSE: NEXUS (サイバーディフェンス・ネクサス)

ネオンサイバー空間を舞台にした本格タワーディフェンスWebゲーム。
スマートフォン・PC両対応、PWA（Progressive Web App）によるオフラインインストール＆単独起動に対応しています。

---

## 🎮 主なゲーム特徴

- **8種類の多彩なタワー**:
  - `パルス砲`: 低コスト・バランス型
  - `バルカン`: 至近距離の敵群れに強い超高速機関砲
  - `レールガン`: 超長射程・単発大ダメージ（対ボス・直線貫通）
  - `クライオ`: 絶対零度の減速冷気（完全凍結・氷破片爆発）
  - `迫撃砲`: 放物線榴弾（クラスター爆撃・放射能汚染ゾーン）
  - `テスラ`: 複数敵への連鎖電撃（EMPスタン・シールド破砕）
  - `レーザー`: 照射継続で威力が急上昇する熱線メルター
  - `シナジーコア`: 周囲のタワーの攻撃力・攻撃速度・射程を強化
- **分岐進化ツリー (Path A / Path B)**:
  - 各タワーLv1〜3強化後、2つの特化進化を選択可能。
- **4つの作戦区域マップ & 2大ゲームモード**:
  - `ALPHA CIRCUIT`: S字基本ライン
  - `TWIN CROSS`: 2方向交差ルート
  - `SILICON MAZE`: 蛇行回路迷路
  - `VORTEX CORE`: 4方向からの総攻撃
  - `キャンペーンモード` & `無限耐久エンドレスモード`
- **司令官アルティメットスキル**:
  - 🛰️ 軌道爆撃 (Orbital Strike)
  - ⚡ EMPサージ (EMP Surge)
  - 🚀 オーバードライブ (Hyperdrive)
  - 💎 緊急補給 (Quantum Supply)
- **量子研究所 (永続強化 Tech Tree)**:
  - ゲームオーバーやクリア時に入手したクォンタムコアを使って、初期資金、攻撃力、攻撃速度、射程、会心率、CD短縮、撃破ボーナス、拠点自動修復を永続強化。
- **24種類の実績アチーブメント & 自動セーブ**:
  - 実績解除でクォンタムコアを獲得。LocalStorageに完全自動保存。
- **プロシージャル・シンセサイザー音響 (Web Audio API)**:
  - 外部音楽ファイルゼロ！軽量オシレーターによるサイバー調BGMと効果音を内蔵。

## 📱 スマートフォンでのPWAインストール方法

1. **Android (Chrome / Edge)**:
   - 画面右上の **「📱 インストール」** ボタン、またはブラウザメニューの「アプリをインストール」をタップ。
2. **iOS (Safari)**:
   - 画面下の共有アイコン ➔ **「ホーム画面に追加」** をタップ。
3. インストール後は全画面アプリとして起動し、電波のないオフライン環境でもプレイ可能です。

## 🛠️ 開発・ビルドコマンド

```bash
# 依存関係のインストール
npm install

# 開発サーバー起動 (http://localhost:5173/)
npm run dev

# プロダクションビルド
npm run build

# ビルドプレビュー
npm run preview
```
